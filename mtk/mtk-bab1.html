Sub-bab 01

Sifat-Sifat Eksponen

Eksponen adalah bentuk perkalian berulang dari suatu bilangan pokok (basis) yang sama. Jika a adalah bilangan real dan n adalah bilangan bulat positif, maka an = a × a × a × ... × a (sebanyak n faktor).

Rumus & Sifat Utama Eksponen
1. am × an = am + n
5. (a / b)m = am / bm
2. am / an = am - n
6. a0 = 1 (untuk a ≠ 0)
3. (am)n = am × n
7. a-n = 1 / an
4. (a × b)m = am × bm
8. am/n = n√(am)
Contoh Singkat: Sederhanakan 23 × 24 / 25
Penyelesaian: 2(3 + 4 - 5) = 22 = 4.
Sub-bab 02

Persamaan Eksponen

Persamaan eksponen adalah persamaan yang pangkatnya (atau bilangan pokok dan pangkatnya) memuat suatu variabel (misalnya x). Kunci menyelesaikannya adalah menyamakan bilangan pokok di ruas kiri dan kanan.

Bentuk Dasar Persamaan Eksponen
• Jika af(x) = ap, maka f(x) = p
• Jika af(x) = ag(x), maka f(x) = g(x)
• Jika af(x) = 1, maka f(x) = 0
• Jika af(x) = bf(x) (a ≠ b), maka f(x) = 0
Contoh Singkat: Tentukan nilai x dari 32x - 1 = 27
Penyelesaian: Ubah 27 menjadi 33 → 32x - 1 = 33 → 2x - 1 = 3 → 2x = 4 → x = 2.
Sub-bab 03

Fungsi Eksponen

Fungsi eksponen memetakan setiap bilangan real x ke bilangan f(x) = k · ax, dengan syarat bilangan pokok a > 0 dan a ≠ 1.

Karakteristik Grafik Fungsi Eksponen

• Monoton Naik (Pertumbuhan): Terjadi jika a > 1 (grafik menanjak ke kanan atas).
• Monoton Turun (Peluruhan): Terjadi jika 0 < a < 1 (grafik menurun ke kanan bawah).
• Asimtot Datar: Grafik selalu mendekati sumbu-X (y = 0) tetapi tidak pernah memotongnya.

Sub-bab 04

Sifat-Sifat Operasi Bilangan Bentuk Akar

Bentuk akar adalah akar dari suatu bilangan rasional yang hasilnya merupakan bilangan irasional (seperti √2, √3, √5).

Aturan Penjumlahan, Pengurangan, & Perkalian Akar
1. p√a + q√a = (p + q)√a
3. √a × √b = √(a × b)
2. p√a - q√a = (p - q)√a
4. √a / √b = √(a / b)
Sub-bab 05

Menyederhanakan Bentuk Akar

Suatu bentuk akar dapat disederhanakan dengan cara memecah bilangan di dalam akar menjadi perkalian dua bilangan, di mana salah satunya adalah bilangan kuadrat sempurna (4, 9, 16, 25, 36, 49, dst.).

Rumus Penyederhanaan
√(a2 × b) = a√b
Contoh Singkat: Sederhanakan √72
Penyelesaian: √72 = √(36 × 2) = √36 × √2 = 6√2.
Sub-bab 06

Merasionalkan Penyebut

Dalam matematika, pecahan yang penyebutnya masih memuat bentuk akar dianggap belum sederhana. Merasionalkan penyebut dilakukan dengan mengalikan pembilang dan penyebut menggunakan akar sekawan.

Pola Perkalian Sekawan
• Bentuk a / √b → kalikan dengan √b / √b
• Bentuk c / (a + √b) → kalikan dengan (a - √b) / (a - √b)
Contoh Singkat: Rasionalkan 6 / √3
Penyelesaian: (6 / √3) × (√3 / √3) = (6√3) / 3 = 2√3.
