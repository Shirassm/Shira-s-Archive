Sub-bab 01

Perintah Dasar Modul Grafik Python Turtle

Python Turtle adalah pustaka grafik bawaan Python yang memungkinkan kita menggambar bentuk geometris dengan menggerakkan kursor pena di atas kanvas.

Perintah Python Turtle Fungsi Utama
p = turtle.Turtle() Membuat objek pena baru bernama p yang akan digunakan untuk menggambar.
p.forward(80) / p.right(90) Menggerakkan pena maju sejauh 80 piksel lalu berbelok ke kanan sebesar 90 derajat (membentuk sudut siku-siku / huruf L).
p.pencolor("blue") Mengubah warna garis lintasan pena menjadi biru.
p.fillcolor("yellow") Menentukan warna isian bidang tertutup (dipanggil sebelum begin_fill()).
p.begin_fill() & p.end_fill() Menandai batas awal dan akhir dari area bidang tertutup yang akan diwarnai.
p.penup() & p.pendown() penup() mengangkat pena agar perpindahan kursor tidak meninggalkan jejak garis; pendown() menurunkannya kembali.
Contoh Soal 1: Jika kursor Turtle dijalankan dengan perintah t.forward(80), t.right(90), lalu t.forward(80), bentuk geometris apakah yang dihasilkan?
Pembahasan: Dua garis tegak lurus yang membentuk sudut 90 derajat (huruf L terbalik), karena baru berjalan dua sisi (belum empat sisi untuk menjadi persegi utuh).
Sub-bab 02

Rumus Sudut Putar Poligon pada Python Turtle

Saat menggambar bangun segi-N beraturan menggunakan perulangan for i in range(N):, kursor Turtle harus berputar sebesar sudut luar bangun tersebut agar kembali ke titik awal dengan tepat.

Rumus Wajib Ujian: Sudut Putar Luar Poligon = 360° ÷ N
• Segitiga Sama Sisi (N = 3): 360 / 3 = 120° (left(120))
• Persegi / Bujur Sangkar (N = 4): 360 / 4 = 90° (left(90))
• Segi Lima / Pentagon (N = 5): 360 / 5 = 72° (left(72))
• Segi Delapan / Oktagon (N = 8): 360 / 8 = 45° (left(45))
Simulator Kanvas Python Turtle (Soal No. 89–92) 
import turtle
t = turtle.Turtle()
t.fillcolor("yellow")
t.begin_fill()
for i in range(3):
    t.forward(100)
    t.left(120)     # Sudut luar segitiga = 360 / 3 = 120 derajat
t.end_fill()
> Sudut putar: 360° / 3 = 120° (Segitiga Sama Sisi)
Contoh Soal 2: Jika Turtle hendak menggambar segi lima beraturan (pentagon) menggunakan for i in range(5):, berapakah sudut rotasi left(...) yang tepat?
Pembahasan: left(72), karena sudut luar segi lima beraturan adalah 360° / 5 = 72°.
Sub-bab 03

Struktur Data list (Array di Python)

list digunakan untuk menyimpan banyak data dalam satu variabel menggunakan kurung siku [...]. Sama seperti array pada C++, nomor urut posisi (indeks) elemen di dalam list selalu dimulai dari 0.

1. Mengakses Indeks data[i] Pada data = [10, 20, 30, 40, 50]:
• data[0] = 10
• data[1] = 20
• data[3] = 40
2. Method .append(), .remove(), & len() • list.append(x): Menambah elemen baru di posisi paling akhir.
• list.remove(x): Menghapus elemen x dari list.
• len(list): Menghitung total jumlah elemen di dalam list.
Simulator Manipulasi List (Soal No. 93 & 94) 
item = ["Buku", "Pensil", "Penggaris"]
item.remove("Pensil")       # Sisa 2 item
item.append("Tipe-X")       # Jadi 3 item
item.append("Spidol")       # Jadi 4 item
print(len(item))
Contoh Soal 3: Diketahui data = [10, 20, 30, 40, 50]. Berapakah hasil dari perintah print(data[1] + data[3])?
Pembahasan: 60. Karena indeks dimulai dari 0, maka data[1] bernilai 20 dan data[3] bernilai 40, sehingga 20 + 40 = 60.
Sub-bab 04

Fungsi: Kata Kunci def dan return

Fungsi adalah blok kode terorganisir yang dapat dipanggil berulang kali. Di Python, fungsi didefinisikan menggunakan kata kunci def.

Perbedaan return vs print() di dalam fungsi: Fungsi yang hanya memakai print() sekadar menampilkan teks ke layar, sedangkan fungsi dengan return mengembalikan nilai hasil perhitungan agar dapat ditampung ke dalam variabel dan diolah kembali pada kalkulasi berikutnya.

Simulator Fungsi cek_diskon(total) (Soal No. 97) 
def cek_diskon(total):
    if total >= 50000:
        return total - 5000
    return total

print(cek_diskon(total_belanja))
Contoh Soal 4: Jika fungsi cek_diskon(total) memotong 5000 hanya jika total >= 50000, berapakah output dari print(cek_diskon(50000), cek_diskon(40000))?
Pembahasan: 45000 40000. Pemanggilan pertama memenuhi syarat >= 50000 sehingga dikurangi 5000 menjadi 45000, sedangkan pemanggilan kedua 40000 tidak mendapat diskon.
Sub-bab 05

Tahapan Pengembangan Perangkat Lunak (SDLC)

Dalam membuat proyek aplikasi atau perangkat lunak yang terstruktur, pengembang mengikuti alur baku SDLC (Software Development Life Cycle) dari tahap perencanaan hingga rilis ke pengguna.

Urutan Tahap SDLC Kegiatan Utama yang Dilakukan
1. Analisis Masalah (Requirement Analysis) Mengidentifikasi kebutuhan pengguna, batasan masalah, serta data input-output yang diperlukan sistem.
2. Desain Algoritma Merancang alur logika penyelesaian masalah secara sistematis sebelum menulis kode.
3. Pemodelan Flowchart / Pseudocode Menuangkan desain algoritma ke dalam bentuk visual diagram alir (flowchart) atau kode semu (pseudocode).
4. Konstruksi Kode (Code Construction) Menulis kode program menggunakan bahasa pemrograman resmi (seperti Python) berdasarkan desain yang sudah dibuat.
5. Quality Assurance & Testing (Pengujian) Tim penguji (tester) melakukan verifikasi untuk menemukan bug, kesalahan logika, maupun celah keamanan sebelum dirilis.
6. Deployment (Rilis & Pemeliharaan) Meluncurkan aplikasi agar dapat digunakan oleh publik serta melakukan pemeliharaan berkala.
Contoh Soal 5: Tahap SDLC di mana tim penguji (tester) melakukan verifikasi penemuan bug, kesalahan logika, dan celah keamanan sebelum aplikasi dirilis ke publik dinamakan apa?
Pembahasan: Quality Assurance & Testing (Pengujian).
