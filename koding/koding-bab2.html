Sub-bab 01

Interpreter, IDE & Aturan Sintaks Python

Python tergolong sebagai interpreted language karena eksekusi kodenya diterjemahkan secara langsung baris demi baris oleh interpreter Python—berbeda dengan Compiler (seperti C++) yang menerjemahkan seluruh kode sekaligus menjadi file eksekusi sebelum dijalankan.

Untuk menulis kode dengan nyaman, programmer menggunakan IDE (Integrated Development Environment) seperti VS Code yang menyediakan editor teks, tombol eksekusi, pelacakan error, serta fitur syntax highlighting (pewarnaan kata kunci agar mudah dibaca).

1. Bersifat Case-Sensitive Huruf besar dan huruf kecil dianggap berbeda. Perintah print("Halo") wajib huruf kecil semua; menulis PRINT("Halo") akan memicu error.
2. String Wajib Diapit Tanda Petik Teks string wajib diapit tanda petik ganda "..." atau tunggal '...' secara berpasangan (tidak boleh campur) agar tidak dianggap nama variabel.
Simulator Cek Sintaks & Case-Sensitivity 
# Uji coba penulisan perintah print() yang benar vs salah:
# 1. print("Selamat Datang")   -> Valid
# 2. PRINT("Selamat Datang")   -> NameError (kapital)
# 3. print(Selamat Belajar)    -> SyntaxError (tanpa tanda petik)
# 4. print("Halo Pembelajar)   -> SyntaxError (petik tidak ditutup)
Contoh Soal 1: Apa perbedaan mendasar antara Interpreter dan Compiler dalam menerjemahkan bahasa pemrograman?
Pembahasan: Interpreter menerjemahkan dan mengeksekusi kode program secara langsung baris demi baris, sedangkan Compiler menerjemahkan seluruh kode sekaligus menjadi bahasa mesin sebelum dijalankan.
Sub-bab 02

Variabel & Tipe Data Dasar

Variabel adalah lokasi penyimpanan data di memori komputer yang diberi nama agar nilainya dapat dipanggil dan diubah secara fleksibel. Di Python, tanda = berarti menyimpan nilai ke dalam variabel (assignment).

Tipe Data Keterangan Contoh Nilai & Hasil type()
int (Integer) Bilangan bulat positif maupun negatif tanpa koma. jumlah = 45 → <class 'int'>
float (Floating Point) Bilangan desimal (berkoma). Hasil pembagian biasa / selalu bertipe float. rata = 88.75 atau 12 / 4 → <class 'float'>
str (String) Kumpulan karakter atau teks yang diapit tanda petik. matpel = "Informatika" → <class 'str'>
bool (Boolean) Nilai kebenaran logika, hanya memiliki dua nilai: True atau False. lulus = True → <class 'bool'>
Aturan Penamaan Variabel Python yang Sah
• Boleh: Huruf, angka, dan garis bawah (_), contoh: total_nilai_siswa, _skor, skor100.
• Dilarang (SyntaxError): Diawali angka (2nd_place, 100_skor), pakai spasi (nama siswa), tanda hubung (nilai-siswa), atau kata kunci Python (while, if, for).
Simulator Pemeriksa Tipe Data & Nama Variabel 
jumlah = 45
rata_rata = 88.75
nama_matpel = "Informatika"
lulus = True
hasil_bagi = 12 / 4   # Pembagian '/' selalu menghasilkan float (3.0)!
Contoh Soal 2: Jika variabel point = 100 lalu dijalankan perintah print(Point), pesan error jenis apakah yang muncul?
Pembahasan: NameError (name 'Point' is not defined), karena Python membedakan huruf besar dan kecil sehingga Point dianggap variabel baru yang belum pernah dibuat.
Sub-bab 03

Fungsi input() & print() (Jebakan Tipe String!)

Fungsi input() mengalirkan data dari pengguna (keyboard) ke program, sedangkan print() mengalirkan hasil dari program ke layar.

Jebakan paling sering keluar di ujian: Secara standar (default), nilai yang dikembalikan oleh input() selalu bertipe str (teks)! Jika langsung dikalikan angka tanpa diubah ke int() atau float(), teks tersebut hanya akan diulang-ulang.

Simulator Jebakan input() Tanpa int() vs Pakai int() 
n = input("Masukkan angka: ")
print("Tanpa int() -> n * 3 =", n * 3)          # String diulang 3 kali!
print("Pakai int() -> int(n) * 3 =", int(n) * 3) # Perkalian matematika!
Contoh Soal 3: Diketahui a = "15" dan b = "25". Apakah hasil dari perintah print(a + b)?
Pembahasan: 1525, karena kedua nilai diapit tanda petik sehingga bertipe string. Operator + pada dua string melakukan penyambungan teks (concatenation), bukan penjumlahan angka.
Sub-bab 04

Operator Aritmatika & Urutan Prioritas Hitung

Selain +, -, dan *, Python memiliki operator khusus untuk pembagian bulat, sisa bagi, dan perpangkatan.

Operator Nama Operasi Contoh & Hasil
** Pangkat (Eksponen) — Prioritas tertinggi! 3 ** 2 → 9 (3 pangkat 2)
/ Pembagian biasa (hasil selalu float) 29 / 6 → 4.8333...
// Pembagian bulat (Floor Division) 29 // 6 → 4 (karena 6 × 4 = 24)
% Modulus (Sisa hasil bagi) 29 % 6 → 5 (sisa dari 29 − 24 = 5)
Simulator Bagi Bulat (//) & Sisa Bagi (%) 
# Kasus Toko Kue (Soal No. 47): Punya 23 kue, tiap dus muat 5 kue
jumlah_dus = kue // kapasitas_dus
sisa_kue   = kue % kapasitas_dus
Contoh Soal 4: Hitunglah hasil dari ekspresi Python print(12 + 4 * 2 ** 3)!
Pembahasan: 44. Kerjakan sesuai urutan prioritas operator:
1. Pangkat terlebih dahulu: 2 ** 3 = 8
2. Perkalian berikutnya: 4 * 8 = 32
3. Penjumlahan terakhir: 12 + 32 = 44.
Sub-bab 05

Operator Perbandingan & Logika Boolean

Operator perbandingan (==, !=, >, <, >=, <=) selalu menghasilkan tipe data bool (True atau False).

Aturan Emas Operator Logika (Prioritas: not → and → or)
• not (Negasi): Membalik nilai kebenaran (not True → False).
• and (Dan): Bernilai True hanya jika KEDUANYA True.
• or (Atau): Bernilai True jika minimal SALAH SATU True.
• == vs !=: == menguji kesamaan nilai, sedangkan != berarti tidak sama dengan.
Simulator Evaluasi Logika (Soal No. 51, 52, 55, 56) 
# Pilih ekspresi logika dari paket soal ASAS untuk melihat langkah hitungnya:
Contoh Soal 5: Jika p = True dan q = False, apakah hasil dari perintah print(not p or q)?
Pembahasan: False. Operator not memiliki prioritas lebih tinggi daripada or, sehingga not p dievaluasi menjadi False terlebih dahulu, lalu False or False menghasilkan False.
