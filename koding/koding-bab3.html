Sub-bab 01

Aturan Indentasi & Percabangan if - elif - else

Berbeda dengan C++ yang memakai kurung kurawal { ... }, Python menggunakan titik dua (:) di akhir pernyataan syarat dan indentasi (spasi atau tab menjorok ke dalam di awal baris) untuk menandai kelompok blok kode tertentu.

1. if (Kondisi Pertama) Memeriksa syarat utama. Jika bernilai False pada if tunggal, blok di dalamnya dilewati dan program lanjut ke baris berikutnya.
2. elif (Else If) Memeriksa syarat alternatif berikutnya apabila kondisi sebelumnya bernilai False. Dipilih saat kondisi bersifat mutually exclusive (hanya satu yang boleh berjalan).
3. else (Alternatif Terakhir) Menampung instruksi cadangan yang dijalankan apabila seluruh kondisi if dan elif di atasnya bernilai False.
4. Wajib Titik Dua (:) Lupa menuliskan tanda titik dua : setelah baris if, elif, atau else akan langsung memicu SyntaxError.
Simulator Percabangan Nilai Grade (Soal No. 61) 
nilai = int(input("Masukkan nilai: "))
if nilai >= 88:
    print("Grade A")
elif nilai >= 75:
    print("Grade B")
else:
    print("Grade C")
Contoh Soal 1: Perhatikan kode: if belanja >= 100000 (tanpa titik dua) lalu di bawahnya print("Dapat Souvenir"). Mengapa kode tersebut memunculkan SyntaxError?
Pembahasan: Karena tanda titik dua (:) tidak dituliskan di akhir baris pernyataan if.
Sub-bab 02

Jebakan Urutan Kondisi pada if - elif - else

Aturan penting: Python membaca percabangan dari atas ke bawah dan akan langsung berhenti mengecek begitu menemukan kondisi pertama yang bernilai True. Oleh karena itu, syarat rentang angka harus disusun dari nilai tertinggi ke terendah.

Simulator Jebakan Urutan Syarat (Soal No. 65) 
# Bandingkan urutan SALAH (kecil ke besar) vs BENAR (besar ke kecil):
skor = 92
if skor >= 70:          # 92 >= 70 sudah True di baris pertama!
    print("LULUS")      # Maka 'CUMLAUDE' di bawah tidak pernah tersentuh!
elif skor >= 90:
    print("CUMLAUDE")
else:
    print("GAGAL")
Contoh Soal 2: Jika skor = 92 dijalankan pada struktur if skor >= 70: print("LULUS") diikuti elif skor >= 90: print("CUMLAUDE"), apakah output yang tercetak?
Pembahasan: LULUS, karena kondisi pertama skor >= 70 sudah terpenuhi lebih dahulu sehingga blok elif di bawahnya dilewati.
Sub-bab 03

Perulangan for & Fungsi range()

Perulangan for digunakan ketika jumlah pengulangan (iterasi) sudah pasti diketahui sejak awal. Fungsi range(start, stop, step) menghasilkan deret bilangan bulat dengan aturan baku: batas akhir (stop) tidak pernah ikut dicetak.

Bentuk range() Aturan Kerja Deret Angka yang Dihasilkan
range(4) Mulai dari 0, berhenti sebelum 4 (stop - 1). 0, 1, 2, 3
range(1, 16) Mulai dari 1, berhenti sebelum 16. 1, 2, 3, ..., 15
range(3, 13, 3) Mulai dari 3, loncat +3, berhenti sebelum 13. 3, 6, 9, 12
range(10, 0, -2) Hitung mundur dari 10, kurangi 2, berhenti sebelum 0. 10, 8, 6, 4, 2
list(range(5, 5)) Batas awal sama dengan batas akhir (tidak ada langkah). [] (list kosong)
Simulator Interaktif range(start, stop, step) 
for x in range(start, stop, step):
    print(x, end=" ")
Contoh Soal 3: Untuk menghasilkan urutan angka ganjil 1, 3, 5, 7, 9 menggunakan fungsi range(), penulisan parameter manakah yang tepat?
Pembahasan: range(1, 10, 2), karena dimulai dari angka 1, bertambah 2 setiap langkah, dan berhenti tepat sebelum angka 10 (yaitu di 9).
Sub-bab 04

Nested Loop (Perulangan Bersarang) & Indentasi

Dalam perulangan bersarang (nested loop), satu siklus lengkap perulangan bagian dalam (inner loop) akan dijalankan untuk setiap satu langkah perulangan bagian luar (outer loop). Total eksekusinya adalah hasil perkalian jumlah iterasi keduanya.

Perhatikan Posisi Indentasi Baris print()!
• Kasus A (Soal No. 79):
for i in range(4):
print("Proses") ← Di dalam loop (4x)
print("Selesai") ← Di luar loop (1x)
Total tercetak = 5 baris.
• Kasus B (Soal No. 80):
for i in range(2):
for j in range(3):
print("Hello") ← 2 × 3 = 6 kali!
Simulator Nested Loop (outer × inner) 
for i in range(outer):
    for j in range(inner):
        print("Hello")
Contoh Soal 4: Berapa kali kata "Hello" dicetak pada kode for i in range(2): yang di dalamnya berisi for j in range(3): print("Hello")?
Pembahasan: 6 kali, berasal dari perkalian 2 × 3 = 6 iterasi.
Sub-bab 05

Perulangan while & Pencegahan Infinite Loop

Berbeda dengan for yang jumlah putarannya pasti, perulangan while terus mengulang blok kode selama syarat kondisinya masih bernilai True, dan berhenti ketika syarat berubah menjadi False.

Bahaya Infinite Loop: Jika variabel penghitung di dalam blok while tidak pernah diubah (misalnya lupa menulis c = c + 1), syarat akan selalu True sehingga program berulang terus-menerus tanpa henti.

Simulator While Loop: Tanpa Update vs Pakai c = c + 1 (Soal No. 77–78) 
c = 1
while c <= 5:
    print(c)
    c = c + 1   # <-- Wajib ada agar nilai c naik menuju 6 dan loop berhenti!
Contoh Soal 5: Pada kode c = 1 diikuti while c <= 5: print(c) tanpa baris penambahan nilai c, apa yang terjadi dan bagaimana cara memperbaikinya?
Pembahasan: Terjadi infinite loop (mencetak angka 1 tanpa henti) karena nilai c selalu tetap 1 (selalu <= 5). Cara menghentikannya adalah menambahkan perintah c = c + 1 (atau c += 1) di dalam blok while.
